## 共享修改

1. 點「開始編輯」，修改行程、備註、網址，或排序、刪除。
   新增前可在工具列選擇日期；編輯列的日期選單可把行程移到另一天，也可使用拖拉把手跨天移動。移動不會自動改時間。瀏覽模式不能移動順序。
2. 點「完成編輯」即同步存檔；需要時開啟 Google 登入，任何已驗證的 Google 帳號都可以發布修改。已登入時停止修改約 2 秒也會自動同步。
3. 顯示「已同步到共享行程」才代表發布完成。失敗時保留編輯模式，再按「完成編輯」重試。朋友重新開啟、切回網站，或在線上瀏覽時等待約 10 秒即可讀取新版。

本機草稿使用 localStorage。離線可看已快取行程，也可編輯；同一頁面恢復連線後，已登入者的本次修改會自動同步。Google Maps 及登入需要網路。

沒有未同步修改時，瀏覽頁會自動載入最新共享版本。有任何未同步新增或修改時，重新整理、離線重開或登入失敗都必須保留草稿，不能自動取代。已登入且草稿基準版本仍等於雲端時，重新連線或重新開啟會嘗試自動同步。頁面顯示目前共享版本號。工具列不提供登入、登出、同步、取回草稿、還原或匯出按鈕。

正在編輯或等待發布的本次修改不會被新版覆蓋；若發生版本衝突，「完成編輯」會顯示選擇視窗，可備份後載入雲端新版、明確同意以整份本機版本覆蓋雲端，或繼續編輯。覆蓋雲端仍有交易版本保護，不會越過之後的新修改。草稿備份保存在 localStorage 的 `hcm_itinerary_supermarkets_v1_draft_backup`，覆蓋前的雲端備份在同鍵加上 `_shared`。

所有登入者都可修改，包括刪除行程；有連結的人不必登入就能查看。

## 網站程式更新

GitHub Pages：Deploy from a branch → main → /(root)。更新檔案並 commit 到 main，GitHub 會自動重新發布。

若改動快取資源，請同時更新 sw.js 的 CACHE 版本；同步程式的版本參數須在 index.html 與 sw.js 保持一致。同步程式連網時優先取新版，離線時使用快取。所有部署路徑保持相對路徑。

雲端行程是目前共享資料來源；單改 index.html 的 original 陣列不會蓋掉已發布的雲端行程。行程内容應在網頁內編輯並同步，版面或功能才改 index.html。

## 同步程式

`cloud-sync.source.js` 是可維護原始碼，`cloud-sync.js` 是網頁使用的本機 bundle。

```sh
npm install
npm run build
```

不要把服務帳號金鑰、Google 存取權杖或其他秘密加入公開 repository。Firebase web config 是公開識別設定，存取控制由 firestore.rules 決定。

Firebase 專案：hochiminh-trip-2026-mei。Firestore Standard 預設資料庫，Spark 免費方案；未連結付費帳單。規則限制單一行程文件的讀取與登入後更新，不允許列出其他文件或刪除文件。修改 firestore.rules 檔案後，還必須在 Firebase 控制台部署規則才會生效。

PWA 可加入主畫面。首次在線上完整開啟後才有離線快取；離線時不會自動上傳修改。
